v1proposed · macOS + linux

Run a tool
from a branch.

relops runs scripts from mozilla-platform-ops repos at any ref. No cloning, no checkouts. Push a branch, send a coworker one command.

Install relops ↓ Overview

01overview

One command, any branch.

relops --ref my-feature relops-infra/path/to/check.sh --verbose

No checkout

Git objects are cached. Each run gets its own throwaway worktree, deleted when the tool exits.

Any ref

Default branch, a branch, a tag, or a full commit SHA. Pushed commits only.

Transparent

Args, stdin, output, exit code and Ctrl-C pass through. The exact SHA is printed to stderr.

Not a sandbox

It doesn't install dependencies or run setup hooks. Tools bring their own prerequisites.

02install

Install in four steps.

You need git, SSH access to GitHub's mozilla-platform-ops org, and whatever runtime the tool you're running expects.

1download for your platform

PlatformDownload
macOS · Apple siliconrelops-darwin-arm64
macOS · Intelrelops-darwin-amd64
Linux · arm64relops-linux-arm64
Linux · amd64relops-linux-amd64

Compare the file against the SHA-256 checksums published with the release. Windows isn't supported in v1.

2make it executable and put it on your PATH

chmod +x relops-* && mv relops-* ~/.local/bin/relops

Make sure ~/.local/bin is in your PATH. On macOS you may need to allow the binary in System Settings → Privacy & Security the first time.

3check GitHub SSH access

ssh -T git@github.com

4confirm it works

relops --version

03usage

Common commands.

default branch

relops relops-infra/path/to/check.sh --verbose

a pushed branch

relops --ref my-feature relops-infra/path/to/check.sh

an exact commit

relops --ref <full-commit-sha> relops-infra/path/to/check.sh

a script that needs an interpreter, using your files

relops --runner python3 --cwd caller relops-infra/path/to/check.py ./hosts.csv

no network, cached refs only

relops --offline --ref my-feature relops-infra/path/to/check.sh

Everything after the repo path goes to the tool untouched. Files the tool writes in its checkout are deleted on exit, so write anything you want to keep elsewhere. Repo and script names above are illustrative.
