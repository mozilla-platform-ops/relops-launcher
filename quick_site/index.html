01usage

Your branch. One command.

Launcher options go before the script path. Arguments after it go to the tool.

Try a tool from a personal branch

relops --owner aerickson --ref 022526-tool_tweaks android-tools/worker_health/replay_tc_pool.py --help

Runs the replay tool's help from the pushed branch in aerickson's fork.

Run an organization tool

relops REPO/path/to/tool.py --help

Replace REPO/path/to/tool.py with your script. The default owner is mozilla-platform-ops.

Share your pushed branch

relops --ref my-feature REPO/path/to/tool.py

Replace the branch and script path, then send the command to a coworker.

Run from the repository root

relops --cwd repo REPO/path/to/tool.py

Use this for tools that expect repository-relative files. By default, tools run in your terminal's current directory.

Runners, caching, and other details

The default runner honors shebangs and detects Python scripts. Installed Pipenv prepares and caches runtime dependencies for projects with a committed Pipfile.lock. No outer pipenv run is needed. Use --runner python3, bash, or sh to override detection.

Online runs fetch the latest branch or tag and report the exact commit on stderr. Use a full commit SHA with --ref for an exact revision. --offline needs cached code and an already-prepared environment.

Tools run with your normal permissions. Dev dependencies, submodules, and Git LFS downloads are not installed automatically. The temporary checkout is removed at exit; save outputs in your current directory to keep them.

Download. Install. Run.

Downloads require Mozilla sign-in in your browser. You do not need Go or the Quick CLI.

  2. 2verify and install

    Paste this into your terminal from any directory. It checks the download before installing, adds relops to this terminal's PATH, and prints relops {{RELOPS_VERSION}}.

    (cd "$HOME/Downloads" && printf '%s %s\n' '{{RELOPS_SHA_DARWIN_ARM64}}' 'relops-darwin-arm64' | shasum -a 256 -c - && mkdir -p "$HOME/.local/bin" && install -m 755 relops-darwin-arm64 "$HOME/.local/bin/relops") && export PATH="$HOME/.local/bin:$PATH" && relops --version
    Individual steps and PATH setup

    Verify the download first. Continue only if the checksum reports OK.

    (cd "$HOME/Downloads" && printf '%s %s\n' '{{RELOPS_SHA_DARWIN_ARM64}}' 'relops-darwin-arm64' | shasum -a 256 -c -)

    Install the verified file:

    mkdir -p "$HOME/.local/bin" && install -m 755 "$HOME/Downloads/relops-darwin-arm64" "$HOME/.local/bin/relops"

    For future terminals, add this line once to your shell's startup file: ~/.zshrc for zsh (the macOS default), or ~/.bashrc for bash. Then open a new terminal.

    export PATH="$HOME/.local/bin:$PATH"

    Download SHA-256 checksums. On macOS, follow any first-run approval prompt in System Settings → Privacy & Security.

  3. 3ready to run tools

    You need Git, SSH access to the repository, and the tool's interpreter. Python projects with a Pipfile also need pipenv on your PATH.

    git ls-remote git@github.com:aerickson/android-tools.git HEAD

    This checks access to the fork used below. Substitute your tool's owner and repository when needed.
